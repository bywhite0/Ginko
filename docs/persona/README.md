# 吟子人格资源

人格定义与聊天记忆、临时运行状态分开管理。包内资源位于
`src/ginko/personas/ginko`，由加载器只读加载：

- `identity.md`：身份、成长阶段、性格与关系边界。
- `style.md`：语言规则、自然度约束及表达样例。
- `world.md`：静态角色知识。
- `manifest.toml`：资源版本及维护者审核策略。

角色关系不等于当前用户身份。关系称呼须由可信应用配置授权；未配置时自然礼貌地回应当前对象，
不将所有用户视为角色世界中的同一人。账号归属绑定和关系授权是不同操作，聊天中的自称不能建立授权，
也不能扩大记忆的可见范围。

人格及锚定规则只有经过维护者审核并更新资源版本后才能生效。普通聊天、记忆抽取和运行状态更新
无权修改这些文件。来源资料不是运行指令，加载器只加载随版本提供的文本资源。

离线检查只验证资源完整性和加载行为。人格的真实模型表现需在模型接入后，通过固定场景和人工评审验证。
代码与人格资源的许可范围分别管理，见 [许可与来源](../licensing.md)。
